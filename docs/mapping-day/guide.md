# Mapping day: guide

This guide explains how to collect accessibility data and share it on OpenStreetMap.

## Before you start

- Pick a public place you can observe yourself.
- Record the source, licence and date for every observation.
- If you did not observe something, write UNKNOWN. Never infer it.

## On the day

1. Take the place's coordinates.
2. Note what you saw: step-free entrance (yes), partial access (limited), no access (no) or UNKNOWN.
3. Write the observation date as YYYY-MM-DD.

## Export your contributions

The export file (osmChange and GeoJSON) is a draft. Nothing is uploaded automatically.

## Submit to OpenStreetMap

A person reviews the file, then submits it themselves using an OpenStreetMap editor. The tool never uploads.
