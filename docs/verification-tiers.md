# Verification tiers

Prototype vocabulary, from the master plan, Part 5, Day 1. There are exactly four tiers.

| Tier | Meaning |
| --- | --- |
| PROTOTYPE-UNVERIFIED | A prototype record that has not been checked on site. Demonstration events in this repository use this tier. |
| SEEDED-OPEN-DATA | A record copied from a named open dataset, with the licence and the download date. An open-data tag is not a measurement by the App. This repository does not seed open data. |
| COMMUNITY-REPORTED | A person reported it. Peer tips use this tier. It is not a surveyed measurement. |
| VERIFIED | Reserved for evidence the prototype cannot produce. No schema in this repository accepts `VERIFIED`. No screen may show a prototype record as verified. |

Unknown stays Unknown. A missing measurement is not filled in.

These tiers are not the same thing as the moderation tiers in `docs/data-governance.md` (V1, V2, V3, C1, C2, C3). Moderation tiers say who reviews a kind of content. Record tiers say how far a fact has been checked.
